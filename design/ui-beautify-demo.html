题目
已知函数 f(x) = x² − 2ax + 3 在区间 [1, 3] 上的最小值为 2，求实数 a 的值。
f(x) = (x − a)² + 3 − a²，对称轴 x = a
AI 解析
1

配方得对称轴 x = a，按 a 与区间 [1, 3] 的位置分类讨论。

2

当 a < 1：最小值 f(1) = 4 − 2a = 2，得 a = 1（舍）。

3

当 1 ≤ a ≤ 3：最小值 f(a) = 3 − a² = 2，得 a = 1。

4

当 a > 3：最小值 f(3) = 12 − 6a = 2，得 a = 5/3（舍）。综上 a = 1。

我的错因
未讨论对称轴在区间左侧的情况，漏掉 a < 1 的分类。
