# 未来新功能创意规划（FUTURE-FEATURES）

> 目的：为「AI 错题本」规划一批**有创意、可落地**的新功能，供后续按优先级挑选实施。
> 视角：基于现有能力（拍照OCR / DeepSeek结构化 / 举一反三 / 复习巩固 / 用户系统 / 云端后端）做增量创新，而非另起炉灶。

---

## 一、创意功能池（按「爽点 / 技术复用 / 工作量」标注）

### 1. 错题知识图谱 + 个人学习雷达 📡
- **创意**：从你所有错题自动抽取知识点（已具备 `knowledge_points`），构建**个人知识图谱**，可视化「哪几个知识点连环错」「薄弱点是孤立的还是成片的」。
- **爽点**：一眼看清"我到底卡在哪"，而不是看一长串题目列表。
- **实现**：后端读错题 → 知识点关系聚合 → 前端画力导向图（Flutter 已有 canvas）。复用现有知识点数据 + 检索层。
- **工作量**：中　**优先级**：高（差异化亮点）

### 2. 智能遗忘曲线复习（预测你会忘哪题）🧠
- **创意**：不止"到期该复习"，而是用**艾宾浩斯 + 每题历史**预测"这道题你大概什么时候会忘"，在遗忘临界点提醒。
- **爽点**：把「被动等提醒」变成「AI 比你先知道你会忘」。
- **实现**：每题记录正确率/间隔 → 拟合遗忘模型 → 复习页排序。复用现有 `review_logs` + 复习页。
- **工作量**：中　**优先级**：高

### 3. AI 错题组卷（针对薄弱点出整套卷）📄
- **创意**：勾选知识点/难度 → AI 从错题 + 生成式变式题**组一套专属小卷**，像老师出卷一样。
- **爽点**：考前针对性刷题，不用自己翻错题本凑。
- **实现**：复用举一反三生成能力（`generateExercisesForQuestion`）+ 错题检索 → 后端组卷接口 + 导出（已有 reportlab PDF）。
- **工作量**：中　**优先级**：高

### 4. 拍照即解 + 自动变式题库 🎯
- **创意**：拍照解析完，自动生成 **3~5 道同知识点变式题**（不同数字/条件/图形），当场巩固。
- **爽点**：一道错题 → 立刻练会整类题，真正"举一反三"。
- **实现**：复用现有举一反三，但**默认自动触发**（现在要手动点）。
- **工作量**：低　**优先级**：高（小而爽）

### 5. 错题语音/短视频复习（通勤听题）🎧
- **创意**：把错题 + 解析转成**语音播报**或**短视频**（题→图卡+语音讲解），通勤/睡前被动复习。
- **爽点**：不占用眼睛，碎片时间学习。
- **实现**：TTS（云厂商/本地）+ 文字转卡面；可导出 mp3/视频。
- **工作量**：中　**优先级**：中

### 6. AI 学习教练（主动对话式）💬
- **创意**：不只是一个"问答框"，而是**了解你错题历史的 AI 教练**——主动问"你这周三角函数错得有点多，要不要我讲讲共性"。
- **爽点**：从"你问它答"变成"它懂你、主动帮你"。
- **实现**：复用 AI 问答（`answerQuestionFollowUp`）+ 错题统计上下文注入。
- **工作量**：中　**优先级**：中

### 7. 错题闪卡（Anki 式间隔重复）🃏
- **创意**：把错题/知识点转成**闪卡**，正面题干、背面解析，按遗忘曲线刷。
- **爽点**：高效刷知识点，配合 #2 遗忘预测。
- **实现**：复用错题数据 → 闪卡刷题 UI + 间隔算法。
- **工作量**：中　**优先级**：中

### 8. 作文 / 主观题 AI 批改 ✍️
- **创意**：语文作文 / 英语写作拍照，AI **评分 + 逐段批注 + 修改建议**（不是只给答案）。
- **爽点**：作文有人"改"了，且能看出提分点。
- **实现**：拍照OCR（已有）+ 专门批改 prompt + 评分维度展示。
- **工作量**：中　**优先级**：中

### 9. 跨科知识点关联 🔗
- **创意**：数学的"函数"、物理的"函数图像"、化学的"变化率"自动关联——**跨学科打通**，提示"你数学函数没弄懂，可能是物理这个坑的来源"。
- **爽点**：打破学科孤岛，找到真正根源。
- **实现**：知识点映射表 + 错题跨科聚合。
- **工作量**：低-中　**优先级**：低（锦上添花）

### 10. 成绩预测 / 提分建议 📈
- **创意**：根据错题量/掌握度/复习情况，预测下次考试区间，并给出「先补哪个知识点提分最快」。
- **爽点**：努力方向可视化，有目标感。
- **实现**：错题统计 + 简单模型 → 雷达 + 建议。
- **工作量**：中　**优先级**：低

## 二、推荐「三步走」落地路线（组合拳）

**第一步（小而爽，快见效）**
- #4 拍照即解自动变式（低工作量）
- #1 知识图谱雷达（差异化亮点）
- #2 遗忘曲线复习（增强现有复习页）

**第二步（提升粘性）**
- #3 AI 组卷（考前刚需）
- #6 AI 学习教练（对话增强）

- #8 作文 AI 批改（扩大学科覆盖）
- #9 跨科关联（独特卖点）

## 五、护城河级深度功能（差异化壁垒）

> 「护城河」= 别人复制不走的东西。它们都建立在**长期积累的独家错题数据**之上，
> 属于「越用越强、越用越难被替代」的深度功能。核心壁垒是**数据飞轮 + 深度个性化 + 网络效应**。

### M1. 个人认知模型（错题数字孪生）🧬 ★最强护城河
- **创意**：用你**全部历史错题**（知识点、错因、掌握曲线、作答模式）训练出一个**你的"认知画像"**——AI 知道"你为什么会错""你适合哪种讲法"。
- **为什么难复制**：这是**独家数据资产**。别家没有你的错题历史，就无法生成你的画像。数据越久越准，形成飞轮。
- **实现**：错题特征化（题型/知识点/错因/时间/掌握度）→ 聚类你的错误模式 → 画像随数据持续更新，注入所有功能（复习/组卷/教练都按"你的画像"定制）。
- **积累**：依赖长期使用，越早启动壁垒越高。

### M2. 专属错题精编教材（一键成书）📕
- **创意**：把你的错题+解析+变式，按你的薄弱点和学习路径**自动排成一本专属《错题精编》**（PDF/纸质），考前打印复习。
- **为什么难复制**：内容是**你独有的错题 + AI 个性化编排**，不是通用题库能替代的；导出即"个人出版"。
- **实现**：复用 reportlab + 组卷能力，按知识点/难度/时间分层编排 + 封面/目录。
- **积累**：错题越多书越"懂你"。

### M3. 错题无感全场景采集（数据护城河）🕸
- **创意**：不只拍照，支持**截图、剪贴板、微信/QQ 分享、网页复制**等方式一键入库；加上批量导入教辅目录。
- **为什么难复制**：采集越顺，错题数据越全，**数据量本身就是壁垒**——用户迁移成本越来越高（换工具=丢积累）。
- **实现**：系统分享面板接入 + OCR/粘贴识别 + 多格式批量导入。
- **积累**：数据规模即护城河。

### M4. 错题因果链追溯 + 学习路径优化 🔗
- **创意**：不只标知识点，而是推理**「这道题为什么错」的前置因果**——"你函数错，可能因为之前的因式分解没掌握"，并给出**最优学习路径**（先补A再补B）。
- **为什么难复制**：需要**跨题、跨知识点、跨时间的推理** + 你的数据做因果建模，深度远超"标签匹配"。
- **实现**：知识点前置关系图 + 你的作答序列 → 因果推断 → 动态学习路径。
- **积累**：历史作答序列越长，因果推断越准。

### M5. 同学错题协同网络（网络效应）👥
- **创意**：同班/同校同学**匿名互推错题、互出变式**——你错的他没错，互相检验；形成「学习圈」。
- **为什么难复制**：**网络效应**——用户越多，互相出的题越多，价值越高，别人很难撬动已有圈子。
- **实现**：用户系统扩展"圈子/好友"，错题匿名交换 + 出题挑战。
- **积累**：用户数即壁垒。

### M6. 长期学习顾问 / 成长档案（3年陪伴）🌱
- **创意**：从你入学到毕业，持续记录**成绩趋势、掌握变迁、方法有效性**，生成"成长档案"和长期建议（这学期该主攻什么）。
- **为什么难复制**：**时间跨度本身就是壁垒**——3年数据是任何后来者无法快速补上的。
- **实现**：长期存储 + 趋势分析 + 阶段性报告。
- **积累**：时间即护城河。

### 护城河一句话总结
**M1 认知画像 + M3 无感采集 + M5 协同网络** 是最核心的三驾马车：
- **M3 负责"把数据攒起来"**（规模护城河）
- **M1 负责"把数据变成只有你有的能力"**（个性化护城河）
- **M5 负责"把单用户变网络"**（网络效应护城河）

三者互相增强：采集越全→画像越准→圈子越大→吸引力越强。这是别人靠钱短时间砸不出来的。

## 六、建议（一句话）

**优先做「#4 自动变式 → #1 知识图谱 → #2 遗忘曲线」这一组**：改动小、立即能感受到"AI 真的懂我的错题"，还能让错题本从"记录工具"变成"学习教练"。

> 注：所有功能都建立在现有「用户系统 + 云端后端 + DeepSeek + 拍照OCR」之上，无技术障碍，主要是产品取舍与排期。
> 护城河功能（M1/M3/M5）建议**尽早埋下数据采集与画像的种子**——它们拼的是积累，越早启动壁垒越深。
