## 1. 背景与现状

### 1.1 现有视觉基础
- 主题：`flex_color_scheme` + `FlexScheme.indigo`，Material 3（[app_theme.dart](../frontend/lib/src/app/theme/app_theme.dart)）
- 浅色 scaffold `#F8FAFC`、深色 `#0F172A`，圆角体系：输入框 10、chip 8、导航指示 10
- 液态玻璃：底部浮动玻璃栏、玻璃顶栏（18 页）、玻璃弹窗/弹层/搜索框/进度条/Toast 已上线
- 设备分档（高/中/低）+ 设置项「玻璃外观」+ 一键回退 Material 已就绪

### 1.2 现状问题（待评审确认）
1. **无统一设计 token**：字号、间距、颜色散落于各页面硬编码，同族组件（卡片/按钮）样式不一致
2. **配色体系单薄**：仅 indigo 一套 seed，状态色（成功/警告/错误）与难度色、科目色未规范化；浅色主题下玻璃对比度偏低（SPEC 已知限制）
3. **页面打磨不均**：首页/错题本已玻璃化，但成就、组卷、复习报告等页面仍是默认 Material 观感
4. **图标/按钮体系**：图标大小、按钮层级（主/次/幽灵）无统一约定
5. **动效零散**：转场已有玻璃转场（高档），但加载骨架屏、空状态插画、微交互缺失
6. **深色模式**：基本可用但卡片层次、分割线对比未经精细调校

## 2. 目标与原则

### 2.1 目标
- 建立**统一设计 token**（颜色/字号/间距/圆角/阴影），全站引用
- 在**不改变信息架构与功能**的前提下提升视觉一致性与精致度
- 保持玻璃分档性能约束不变（低档 minimal 不新增重效果）

### 2.2 原则
- **先 token 后页面**：所有美化通过 token + 主题驱动，禁止页面级硬编码颜色/字号
- **零功能回归**：不改路由、不改交互逻辑，仅视觉层
- **可回退**：每个阶段独立提交，出问题可整段回退
- **先备份后动手**：开工前对 frontend 做一次完整备份

### 2.3 明确不做
- 不更换信息架构、不增删功能
- 不引入新的大型 UI 框架/动画库
- 不做逐行玻璃等 SPEC 已禁止的高风险效果

## 3. 实施分期

### Phase 0：备份与基线（前置）
- 对 `frontend/` 完整备份（沿用 `AI-wrong-backup_YYYYMMDD_HHMMSS` 惯例）
- 采集 6 个核心页面（首页/错题本/复习/设置/详情/组卷）浅色+深色截图作为改造前基线

### Phase 1：设计 Token 体系（P0）
在 `lib/src/app/theme/` 新增/扩展：
- **颜色 token**：主色、辅助色、中性灰阶（≥8 级）、成功/警告/错误、难度色（易/中/难）、科目色（数/语/英/理/化…），深色模式全套映射
- **文字 token**：字阶（12/14/16/20/24/32 映射 M3 textTheme）、字重、行高
- **间距 token**：4/8/12/16/24/32/48
- **圆角 token**：8（小件）/10（输入）/12（卡片）/16（弹层）
- **阴影 token**：2 级（卡片轻阴影 / 弹层深阴影）
- 输出：`app_tokens.dart` + 改造 `app_theme.dart` 全量引用 token
- 验收：全项目 grep 不到页面内硬编码色值（白名单：玻璃 shader 内部）

### Phase 2：全局主题与组件规范化（P1）
- 统一卡片样式（圆角/边距/阴影，二选一：1px 描边 或 轻阴影）
- 统一按钮层级：主（填充）/ 次（描边）/ 文字按钮，hover/press 态按主色加深 10%
- 统一图标尺寸：行内 20、独立 24；梳理现有图标混用
- 输入框、chip、dialog、snackbar 全部走 token
- 深色模式专项：卡片表面层级、分割线可见度、玻璃在深色下的着色微调
- 浅色主题玻璃对比度修复（SPEC 已知限制）：提高玻璃底色不透明度或加深文字

### Phase 3：重点页面打磨（P2，按优先级）
1. **首页**：统计卡/额度卡信息层级重排，空状态插画/引导，拍照主按钮视觉强化
2. **错题本**：列表卡片排版（题图/题干摘要/标签/时间），筛选栏与搜索框间距节奏
3. **错题详情**：题干区/解析区/同类题区分区清晰，LaTeX/图片排版规范
4. **复习页 + 复习报告**：进度可视化、结果页数据呈现
5. **组卷流程**：步骤指示、难度/科目选择器样式统一
6. **成就页**：徽章网格、进度条走 token
7. **设置页**：分组间距、条目密度统一（沿用 GlassListTile solid 风格）

### Phase 4：动效与空态（P3）
- 统一加载骨架屏（错题列表/详情/统计）
- 空状态插画 + 引导文案（错题本空/搜索结果空/复习完成）
- 列表入场交错动画（低档设备自动关闭）
- 可选：C2 `GlassMaterialize` 页面出现动画、ProgressiveBlur 按滚动偏移启用（SPEC 已备注）

### Phase 5：验收与回归（P4）
- 逐页截图对比（玻璃开/关 × 浅色/深色 × 高/中/低档关键页）
- 性能回归：错题本滚动帧率不低于现状（低档 ≥50fps / 中档 ≥55fps）
- 可访问性：文字对比度 ≥4.5:1 抽检
- 功能回归清单沿用 SPEC-LIQUID-GLASS §7
- 真机验证（Redmi M511CD + 1 台中低端机）

## 5. 风险与缓解

| 风险 | 缓解 |
|---|---|
| token 替换触及大量文件，引入视觉回归 | 每阶段独立提交；Phase 1 只建 token 不改页面，Phase 2 起逐页替换 |
| 浅色玻璃对比度调整影响深色观感 | 浅/深分开调校，截图对比验收 |
| 动画增加低档机负担 | 低档默认关闭入场动画，跟随「减弱动态」系统设置 |
| 页面打磨主观返工 | Phase 3 前先做首页 1 页样张确认风格，再批量推进 |
