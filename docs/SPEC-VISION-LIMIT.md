# 功能规格 — 视觉模式限流与降级（最终版）

> 版本：v2.0　状态：已评审　来源：用户多轮细化

## 1. 需求澄清

### 1.1 核心规则
| 用户类型 | 视觉兜底限制 | 超限行为 |
|---|---|---|
| **无 Key 用户**（未配置/跳过） | 视觉兜底**总共最多 10 次**（累计非每天） | 回退基础 OCR + 提示 |
| **有 Key + 未启用视觉** | 后端自带 Key 视觉兜底，**50 次/IP/天** | 回退基础 OCR + 提示 |
| **有 Key + 启用视觉** | 用户 Key 直连；Key 失效→降级自带 Key 兜底（50次/IP/天） | 回退基础 OCR + 提示 |

### 1.2 关键点
- **不强制**首次配置 Key：用户可选「不使用 Key」跳过。
- **设置里添加 DeepSeek** 时，需**询问是否启用视觉**。
- 超限后提示：**「DS 视觉识别已回退到基础 OCR，重新填写 Key 即可继续使用」**。

## 2. 功能需求

### 2.1 后端限流改造
- 区分「无 Key（累计 10 次）」与「有 Key（每天 50 次/IP）」。
- analyze 视觉兜底前：
  - 请求带用户 Key 且启用视觉 → 用用户 Key（失效降级自带 Key）
  - 无用户 Key → 判断累计次数（≤10）再自带 Key 兜底
- 超限返回：HTTP 400 + `detail` 含「已回退基础 OCR」提示。

### 2.2 前端配置向导
- 供应商页：允许「不使用 Key」跳过（默认不强制）。
- 选择使用 Key → 填供应商 + Key。
- 识别模式页：无 Key 用户直接标准模式；有 Key 用户可选择视觉模式。

### 2.3 设置页
- 添加/编辑 DeepSeek 时询问是否启用视觉模式。

### 2.4 超限/失效提示
- 醒目提示「DS 视觉识别已回退到基础 OCR，重新填写 Key 即可继续使用」。

## 3. 验收标准
- [ ] 无 Key 用户可跳过配置，视觉兜底累计 ≤10 次后回退基础 OCR
- [ ] 有 Key + 启用视觉 → 用户 Key 直连，失效降级自带 Key
- [ ] 设置里添加 DeepSeek 询问是否启用视觉
- [ ] 超限后醒目提示「已回退基础 OCR，重新填写 Key」

## 4. 明确不做
- 用户 Key 上传到后端（视觉模式前端直连）
